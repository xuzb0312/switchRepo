# GameShare - 游戏分享平台

> 微信小程序 + Java后台 | 分享Switch及各类游戏，支持网盘下载链接

## 项目结构

```
game-share/
├── miniprogram/        # 微信小程序前端
└── backend/            # Java后台管理
```

## 功能规划

- [ ] 用户注册/登录
- [ ] 游戏发布（支持Switch/PS/Xbox/PC等平台）
- [ ] 网盘链接管理（阿里云盘/百度网盘等）
- [ ] 游戏列表/搜索/筛选
- [ ] 游戏详情页（含下载链接）
- [ ] 后台管理（游戏审核/用户管理/链接管理）

## 技术栈

**小程序**: 原生开发 / TDesign / Vant Weapp
**后台**: Spring Boot + MyBatis + MySQL
